一、 架构与布局大改版（最直观的变化）
双栏联动布局（Firefox 风格）：从最初单栏的“树+右侧表单”，变成了如今左侧结构化树、右侧书签列表、底部属性面板的经典专业布局。
彻底解决“死循环卡死”：弃用了 Tkinter 容易引发无限递归的 <TreeviewSelect> 事件，改为鼠标点击释放（<ButtonRelease-1>）触发，彻底告别了点击就 CPU 100% 卡死的恶性 Bug。
状态栏同步：底部状态栏实时显示操作提示，右侧固定显示数据库的“创建时间”。
二、 数据安全与加密（看不见但最重要）
原子写入与防损坏：写文件时采用临时文件 + 覆盖机制（os.replace），并自动生成 .bak 备份，防止断电或崩溃导致数据全毁。
单实例锁：防止同时打开两个窗口导致数据互相覆盖。
绿色便携化：数据库 bookmarks.vault 直接生成在 EXE 同目录下，拷到 U 盘就能带走。
三、 书签与文件夹管理
树内直接显示书签：左侧树现在可以像 Windows 资源管理器一样，展开文件夹看到里面的所有书签。
底部详情编辑面板：选中右侧列表的书签，底部即可修改名称、网址，无需弹窗。
文件夹自由重命名/删除：修复了之前无法重命名根文件夹、无法删除唯一文件夹的 Bug。
本地自定义图标：支持为每个书签上传本地的 PNG/GIF 图标，且支持一键恢复默认。
四、 高级交互（拖拽与复制粘贴）
全功能拖拽系统：
文件夹互拖（防套娃死循环）。
右侧书签直接拖入左侧任意文件夹。
拖拽实时高亮（浅蓝=放入，浅黄=插前/插后）。
鼠标变十字图标，拖到边缘自动平滑滚动，状态栏实时提示。
快捷键复制粘贴：支持 Ctrl+C / Ctrl+V 快速复制书签或整个文件夹（包括里面的内容）。
五、 数据导入功能
HTML 书签解析器：支持一键导入 Chrome / Edge / Firefox 导出的 .html 书签文件，完美保留原层级嵌套结构。
六、 视觉与 UI 体验
完美的高 DPI 缩放：锁定了最高 1.25 倍缩放，彻底解决了 4K 屏幕下窗口巨大、文字被截断（裁边）的问题，行高自动适配字体。
一键深色/浅色模式：全局应用深色主题（包括输入框、列表、右键菜单），并自动记忆偏好。
精美内置图标：使用代码绘制了不会因缩放模糊的实心大色块图标（根文件夹深蓝，子文件夹浅蓝，书签黄色）。
表单对齐与居中：登录界面密码框精确对齐，密码显示/隐藏（👁）；所有弹窗自动计算屏幕中心位置，绝不跑到左上角。
七、 异常处理机制
全局崩溃捕获：任何未知错误都不会导致软件“闪退消失”，而是弹窗提示并自动生成 crash.log 记录详细原因，方便排查。
八、 搜索与过滤
实时搜索框：顶部搜索框支持实时检索当前选中文件夹下的书签名称和网址。
